# 安装

不勾选“将Code注册为受支持的文件类型的编辑器”

其他全部勾选



这个选项会让 VS Code 成为**特定文件类型的默认打开程序**。具体来说：

| 文件类型 | 示例                                             |
| :------- | :----------------------------------------------- |
| 代码文件 | `.js`, `.ts`, `.html`, `.css`, `.py`, `.java` 等 |
| 文本文件 | `.txt`, `.md`, `.json`, `.xml`, `.yml` 等        |
| 配置文件 | `.ini`, `.conf`, `.config` 等                    |

✅ **如果你勾选了这个选项：**

- 双击代码文件时，会自动用 VS Code 打开
- 文件图标会显示为 VS Code 的样式
- 右键菜单会出现"用 VS Code 打开"的选项
- 更方便快捷地编辑代码文件

❌ **如果不勾选：**

- 双击代码文件时，会用系统默认的其他编辑器打开（如记事本、其他IDE等）
- 需要手动右键选择"用 VS Code 打开"，或先打开 VS Code 再拖入文件

# 缩进

两格缩进和四格缩进本质上是**代码风格偏好**的区别，没有绝对的对错，但在不同场景下有各自的惯例和考量：

## 核心差异

| 维度         | 2 格缩进                   | 4 格缩进                     |
| :----------- | :------------------------- | :--------------------------- |
| **视觉密度** | 更紧凑，同屏能看到更多层级 | 层级更清晰，适合嵌套深的代码 |
| **屏幕空间** | 行长度更短，适合小屏/分屏  | 占用更多水平空间             |
| **可读性**   | 适合层级多但结构简单的代码 | 适合逻辑复杂、嵌套深的代码   |

## 社区惯例

不同语言/生态有默认偏好：

- **2 格**：JavaScript/TypeScript、JSON、Vue、React、Ruby、HTML/CSS
- **4 格**：Python（PEP 8 强制要求）、Java、C/C++、C#、PHP、Go

## 在 VS Code 中的设置

JSON

```json
// settings.json
{
  "editor.tabSize": 2,        // 或 4
  "editor.insertSpaces": true, // true=空格，false=Tab
  "editor.detectIndentation": true // 自动检测文件当前缩进风格
}
```

也可以点击右下角状态栏的 **"Tab Size"** 快速切换当前文件的缩进。

## 实际建议

1. **团队优先**：跟着项目现有的 `.editorconfig` 或团队规范走，保持一致比个人偏好重要
2. **语言优先**：写 Python 就用 4 格，写前端就用 2 格，符合社区预期
3. **深度嵌套时**：如果代码经常出现 4 层以上的嵌套，4 格缩进更容易看清结构；2 格在深层嵌套下容易"挤成一团"

简单来说：**2 格省空间，4 格显结构。入乡随俗即可**

# 说明

vscode在单击某个文件后，文件名显示字体为斜体

此时若单击另一个文件，会直接切换

双击某文件，或对文件进行修改，文件名显示字体不为斜体，

此时若单击另一个文件，会新起一个栏目
