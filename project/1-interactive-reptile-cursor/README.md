# AI

这是一个基于 **HTML5 Canvas 的 2D 逆运动学生物模拟系统**。它通过层级关节、物理约束和状态机，实现了触手抓取、多足行走等仿生运动。

------

## 一、项目涉及的知识领域

### 1. 编程与 Web 基础

- **JavaScript/ES6**：类、继承、闭包、事件监听
- **Canvas 2D API**：路径绘制、动画循环、实时渲染
- **DOM 操作**：动态创建画布、鼠标/键盘输入抽象

### 2. 数学基础

- **三角函数**：`sin/cos/atan2` 用于角度与坐标转换
- **向量运算**：距离计算、向量归一化、点积思想
- **角度规范化**：处理 360° 环绕问题，确保旋转平滑

### 3. 计算机图形学与动画

- **正向运动学（FK）**：从父关节逐级推算子关节位置
- **逆运动学（IK）**：从末端目标反推关节角度（CCD 算法）
- **层级变换链**：父子骨骼树的递归更新与绘制

### 4. 物理模拟

- **质点动力学**：加速度→速度→位移的积分模型
- **摩擦与阻力**：线性阻力衰减、静摩擦阈值
- **弹性约束**：关节刚度（stiffness）与活动范围（range）的限位

### 5. 仿生学与状态控制

- **步态状态机**：站立（Stance）↔ 摆动（Swing）的切换逻辑
- **落足点规划**：基于髋关节位置与摆动方向计算落脚点
- **多足协调**：所有腿站稳时才全速前进，迈步时减速

### 6. 数据结构与算法

- **树形结构**：骨骼的父子层级关系
- **递归遍历**：关节链的更新、绘制、跟随
- **数组/链表**：肢体节点链的存储与反向迭代

## 二、学习路径建议

### 阶段一：JavaScript + Canvas 基础（2~3 周）

- 掌握 Canvas 路径绘制与动画循环
- 实践：做跟随鼠标移动的小球、键盘控制的物体
- **里程碑**：能独立写出 60fps 的平滑动画

### 阶段二：数学与向量（1~2 周）

- 理解弧度制、`atan2`、极坐标转直角坐标
- 实践：让箭头始终指向鼠标，画一个动态时钟
- **里程碑**：输入"起点+角度+长度"，能算出终点坐标

### 阶段三：正向运动学（1~2 周）

- 建立父子层级，理解相对角度与绝对角度
- 实践：做 3~5 段的机械臂/蛇形链条
- **里程碑**：头部跟随鼠标，身体像链条一样自然拖动

### 阶段四：逆运动学（2~3 周）

- 学习 CCD（循环坐标下降）算法
- 加入关节角度限制和骨骼长度约束
- **里程碑**：触手末端能精准触达鼠标位置，关节不折断

### 阶段五：物理与仿生（2~3 周）

- 给物体加上惯性、摩擦、阻力
- 实现简单状态机（站立/迈步）
- **里程碑**：小车有"重量感"，多足生物能自动交替行走

### 阶段六：综合实战（2~4 周）

- 复现代码中的触手、鱿鱼、蜥蜴等场景
- 自行扩展：加翅膀、改步态、换形态
- **里程碑**：能独立修改并创造出新的仿生生物

## 四、最高效的学习建议

1. **以项目驱动**：每个阶段都要有一个"能跑起来"的小作品，不要只看书
2. **从 1 个关节开始**：先写 1 段骨骼，再加到 3 段、10 段，不要一上来就写多足生物
3. **先抄后改**：把这段代码复制下来，改参数（如 `stiffness`、`range`），观察变化
4. **可视化调试**：在 Canvas 上画出角度线、目标点、速度向量，用肉眼理解数据
5. **推荐资源**：
   - MDN Canvas 教程（官方权威）
   - 《代码本色》（*Nature of Code*，中文有译本，专门讲代码模拟自然）
   - YouTube 搜索 "2D Inverse Kinematics CCD"（可视化讲解比论文快 10 倍）
